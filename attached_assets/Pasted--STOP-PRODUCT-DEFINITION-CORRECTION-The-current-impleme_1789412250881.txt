# HOW THE PYTHON INJECTOR SHOULD WORK

The injector should implement the known working architecture:

1. Leica FOTOS establishes the authorized camera relationship/session.

2. User leaves the camera/FOTOS state in the known working condition.

3. Python injector connects to the Leica camera using the proven PTP/IP implementation.

4. Reuse/inherit the valid existing FOTOS-authenticated state as demonstrated by existing working code.

5. Perform the known session initialization behavior.

6. Read camera information if required.

7. Read current Look state/table using the known Leica operation.

8. Validate that the camera/session is in the expected state.

9. Upload the generated Look payload using the known write operation.

10. Read the Look table again.

11. Verify:

ID

name

base

and other known fields where possible.

12. Report success/failure clearly.

Do NOT make the user edit binary structures manually.
